# Koah

> Koah is an ad network for AI applications: publishers embed native ads inside chat and agent experiences through an SDK, and advertisers reach users with placements matched to first-party query intent at inference time.

Notes for agents:

- Developer documentation lives at https://docs.koahlabs.com, which publishes its own llms.txt covering SDK installation, platform guides, and the API. Prefer it for integration questions.
- The homepage and every blog, changelog, customer, and guide page on this site return markdown when fetched with an `Accept: text/markdown` header.
- Content signals (see /robots.txt): search=yes, ai-input=yes, ai-train=no. Do not use this content for model training.
